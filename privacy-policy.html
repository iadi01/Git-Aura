Privacy Policy

Last Updated: January 2026

1. Introduction

Welcome to GitAura. We prioritize the security of the developer community. This policy explains our "Zero-Storage" philosophy and how we interact with the GitHub REST API and Google AdSense.

2. Data Collection & Analysis

GitHub Analytics: GitAura analyzes public GitHub statistics. We do not collect private emails, passwords, or personal identification. All analysis is performed on public data already shared by you on GitHub.

3. Zero-Storage Architecture

Unlike other GitHub profile analyzers, GitAura operates on a client-side basis. Data fetched from the GitHub API remains in your browser's temporary memory. We do not own, operate, or maintain a database that stores user profile data.

4. Advertising & Cookies

To keep GitAura free for developers, we use Google AdSense. Google uses cookies (like the DART cookie) to serve relevant ads based on your visit to this and other sites on the internet.

  • You can opt-out via Google Ads Settings.
  • Third-party vendors use cookies to track anonymous usage statistics.

5. Log Files & Performance Analytics

We monitor log files (IP addresses, browser type, timestamp) to prevent API abuse and optimize site performance. This data is not linked to any personally identifiable information.

6. Security

We utilize HTTPS encryption to ensure that the requests between your browser and the GitHub API are secure and cannot be intercepted by third parties.
